Value, hash y segmentos

Value encoding

Enteros: se guardan operando sobre el propio valor. «Diccionario innecesario» de la diap. 13 (ShopId).

Hash encoding

Textos y valores dispersos: diccionario + IDs. El tamaño del diccionario crece con la cardinalidad.

La dimensión tiempo, en vivo

EVALUATE VAR _fechas = CALENDAR ( DATE ( 2024, 1, 1 ), DATE ( 2024, 12, 31 ) ) RETURN ADDCOLUMNS ( _fechas, "Año", YEAR ( [Date] ), "Mes", MONTH ( [Date] ), "Nombre mes", FORMAT ( [Date], "mmmm" ), "Trimestre", "T" & QUARTER ( [Date] ), "Semana ISO", WEEKNUM ( [Date], 21 ), "Día semana", WEEKDAY ( [Date], 2 ), "Laborable", WEEKDAY ( [Date], 2 ) <= 5, "Año fiscal", "AF" & YEAR ( EDATE ( [Date], 6 ) ) ) 
let
    Inicio = #date(2024, 1, 1),
    Fin = #date(2024, 12, 31),
    Dias = Duration.Days(Fin - Inicio) + 1,
    Fechas = List.Dates(Inicio, Dias, #duration(1, 0, 0, 0)),
    Tabla = Table.FromList(Fechas, Splitter.SplitByNothing(), {"Fecha"}),
    Tipada = Table.TransformColumnTypes(Tabla, {{"Fecha", type date}}),
    ConAnio = Table.AddColumn(Tipada, "Año", each Date.Year([Fecha]), Int64.Type),
    ConMes = Table.AddColumn(ConAnio, "Mes", each Date.Month([Fecha]), Int64.Type)
in
    ConMes
WITH fechas AS (
    SELECT CAST('2024-01-01' AS date) AS Fecha
    UNION ALL
    SELECT DATEADD(DAY, 1, Fecha)
    FROM fechas WHERE Fecha < '2024-12-31'
)
SELECT Fecha,
       YEAR(Fecha)               AS Anio,
       MONTH(Fecha)              AS Mes,
       DATEPART(ISO_WEEK, Fecha) AS SemanaISO
FROM fechas
OPTION (MAXRECURSION 400);

Funciones de usuario (UDF) GA jun. 2026 según fuentes secundarias 🔎

DAXudf.dax · sintaxis a confirmar
DEFINE
    FUNCTION PctDe = ( n : VAL, d : VAL ) =>
        DIVIDE ( n, d )
EVALUATE
ROW (
    "pct", PctDe ( [Ventas], [Ventas Totales] )

VAL

Evalúa el argumento una vez, en el contexto de quien llama.

EXPR

Lo evalúa donde se usa dentro de la función; puede hacerlo varias veces.

Objetivo: reutilizar y mantener, no acelerar. Medir siempre frente a la versión sin UDF.
